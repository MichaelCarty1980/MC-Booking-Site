# michael-carty-site

Michael Carty Bookings & Artist Management — static artist roster + booking site.

- 7 pages: Home, Artists, Booking, Management, About, News, Contact
- Booking + Contact forms POST to `mail.php` → `bookings@michael-carty.com`
- Includes `mail-smtp.php` for reliable SMTP delivery on a VPS
- Deploy to any host with PHP (Hostinger cpanel, or a Linux VPS)

See [DEPLOY_FRIEND.md](DEPLOY_FRIEND.md) for the full step-by-step.
